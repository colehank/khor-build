# Paired observer calibration

`netlab-workload-observer` is a fixed SSH-only task under the original Turing
UID, lock, namespace, tools, disk, jobs and deadline guards. It first executes
`workload::observer::w3_` once. A failed ownership/recording calibration prevents
the six workload cases from running, and its raw evidence remains available.

Then it runs the predeclared order streaming/buffered/buffered/streaming/
streaming/buffered, one case at a time. A case failure does not discard later
outcomes. The first failing command's status is kept. The source-owned parser
`scripts/netlab-observer.py` comes from the exact verified product tree and
checks every sample, order, cancellation calibration, timer trace and actual
device/gateway profile. Its own metadata tests execute no product or network.

Each mode has three samples of the complete experiment, not a p99 population.
The odd paired order is only partially balanced. This measures the observer,
does not change production queues and does not accept Node performance, process
exit, phone or energy requirements.
